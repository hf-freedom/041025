## 二、主要流程

项目包含以下4个主要功能模块/流程：

| 序号 | 流程名称 | 功能描述 |
|------|----------|----------|
| 1 | 今日打卡流程 | 添加、编辑、删除今日运动记录 |
| 2 | 历史记录流程 | 查看和管理所有历史运动记录 |
| 3 | 日历视图流程 | 以日历形式查看打卡情况 |
| 4 | 统计流程 | 查看本周/本月运动统计数据 |

## 三、流程详细步骤

### 3.1 今日打卡流程

#### 流程步骤

```
1. 用户选择运动项目 (预设或自定义)
      ↓
2. 系统自动设置记录类型 (时长/次数)
      ↓
3. 用户输入运动数值
      ↓
4. 点击"打卡记录"按钮提交
      ↓
5. 系统生成记录并保存到localStorage
      ↓
6. 更新今日汇总统计数据
```

#### 详细说明

**步骤1: 选择运动项目**
- 用户从下拉列表选择预设运动（如跑步、瑜伽、游泳等）
- 或选择"自定义运动"输入自定义名称

**步骤2: 自动设置记录类型**
- 预设运动会自动设置对应的记录类型
- 例如：跑步默认为"时长"类型，俯卧撑默认为"次数"类型

**步骤3: 输入运动数值**
- 时长类型：输入运动时长（分钟/秒）
- 次数类型：输入运动次数/组数

**步骤4: 提交记录**
- 验证必填字段
- 生成唯一ID
- 记录当前日期和时间戳

**步骤5-6: 保存和更新**
- 数据持久化到localStorage
- 实时更新页面显示

---

### 3.2 历史记录流程

#### 流程步骤

```
1. 切换到"历史记录"标签页
      ↓
2. 系统加载所有历史记录
      ↓
3. 按时间倒序展示记录列表
      ↓
4. 用户可进行编辑或删除操作
```

#### 详细说明

**步骤1-2: 加载数据**
- 从localStorage读取所有记录
- 使用`loadFromStorage()`方法

**步骤3: 展示列表**
- 记录按创建时间倒序排列
- 显示运动名称、日期、详情

**步骤4: 操作记录**
- 编辑：打开编辑模态框修改记录
- 删除：确认后删除记录

---

### 3.3 日历视图流程

#### 流程步骤

```
1. 切换到"日历视图"标签页
      ↓
2. 系统渲染当前月份日历
      ↓
3. 标记有运动记录的日期
      ↓
4. 用户可切换月份查看
      ↓
5. 点击日期查看当日记录详情
```

#### 详细说明

**步骤2: 渲染日历**
- 计算当月第一天和最后一天
- 填充上月和下月的日期补全6行

**步骤3: 标记记录**
- 有运动记录的日期显示绿色背景
- 当天日期有边框标识

**步骤4: 切换月份**
- 点击左右箭头切换上/下月
- 自动更新日历视图

**步骤5: 查看详情**
- 点击日期显示当日所有记录
- 可进行编辑和删除操作

---

### 3.4 统计流程

#### 流程步骤

```
1. 切换到"统计"标签页
      ↓
2. 系统自动计算本周统计数据
      ↓
3. 系统自动计算本月统计数据
      ↓
4. 展示统计结果
```

#### 详细说明

**本周统计**:
- 计算本周一至周日的记录
- 统计运动总次数和累计时长

**本月统计**:
- 计算本月第一日至最后一日的记录
- 统计运动总次数和累计时长

## 六、数据类型定义

### ExerciseRecord - 运动记录

```typescript
interface ExerciseRecord {
  id: string          // 唯一标识符
  name: string        // 运动名称
  type: RecordType    // 记录类型：'duration' | 'count'
  duration?: number   // 时长（type为duration时有值）
  count?: number      // 数量（type为count时有值）
  unit?: string       // 单位
  date: string        // 日期（YYYY-MM-DD）
  createdAt: number   // 创建时间戳
}
```

### ExerciseOption - 运动选项

```typescript
interface ExerciseOption {
  name: string        // 运动名称
  type: RecordType    // 默认记录类型
  unit: string        // 默认单位
}
```

### RecordType - 记录类型

```typescript
type RecordType = 'duration' | 'count'
```

## 八、数据持久化

项目使用 **localStorage** 进行数据持久化：

- **存储键**: `exercise-records`
- **数据格式**: JSON字符串数组
